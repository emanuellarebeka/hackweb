# Entrega

## Resumo

O projeto entrega uma interface simples para:

1. Registrar serviço.
2. Validar registro.
3. Certificar registro.

## Itens principais

- Frontend em `app/`
- Smart contract em `contracts/`
- Deploy em `scripts/`
- Documentação resumida em `docs/`

## Estado atual

- Interface local funcional
- Integração opcional com MetaMask
- Fluxo visual reduzido para `Enviado`, `Validado` e `Certificado`
