# Segurança

## Resumo

- `ethers` local, sem CDN externa.
- CSP ativa no frontend.
- Escape de conteúdo antes de renderizar no histórico.
- Evidência completa fora da blockchain.
- Blockchain usada para registro essencial e rastreabilidade.

## Antes de produção

1. Auditar o contrato.
2. Usar carteira dedicada.
3. Definir política de validadores.
4. Garantir backup das evidências.
